# ◈ JsonLens · 結構透鏡

> 🌐 **語言 / Language**：<a href="README.md">简体中文</a> · <a href="#/">繁體中文</a> · <a href="README.en.md">English</a>

**JsonLens** 是一款 **零依賴、可離線、瀏覽器端執行的 JSON / YAML / TOML / CSV 結構視覺化與智能編輯工作台**。它把複雜的資料檔案渲染成可摺疊的彩色結構樹，讓你既能「一眼看懂」，又能「直接編輯」——而這一切都發生在本機瀏覽器裡，**資料不出本機，絕不上傳雲端**。🔒

> 🐣 **靈感來源**：`jless` 這類終端工具只能「看」不能「改」，`jq` 又需要寫過濾器、學習曲線陡峭；而線上 JSON 檢視器會把你的敏感配置傳到第三方伺服器。JsonLens 填補了「**本機視覺化 + 可編輯 + 多格式互轉**」這個空白，開箱即用、隱私無憂。

---

## ✨ 核心特性

- 🗂️ **多格式解析與互轉**：原生支援 **JSON / YAML / TOML / CSV** 四種格式，一鍵互相轉換，資料無損往返。
- 🌳 **彩色結構樹**：物件/陣列自動摺疊，按型別著色（字串🟢 / 數字🟠 / 布林🟣 / null⚪），巢狀層級一目了然。
- ✏️ **視覺化直接編輯**：雙擊任意標量即可內聯修改，節點支援 **新增 / 刪除 / 上移 / 下移**，所見即所得。
- 🔍 **智能搜尋高亮**：在樹中即時搜尋並高亮匹配節點，快速定位深層資料。
- ◐ **敏感值脫敏**：一鍵把 `password`、`apiKey`、`token` 等敏感欄位打碼為 `••••••••`，簡報分享更安心。**重點加粗**。
- 📊 **結構統計面板**：即時統計節點總數、最大深度、資料大小、型別分佈，洞悉資料全貌。
- 🔧 **格式化 / 壓縮 / 排序**：一鍵格式化縮排、壓縮為單行、按鍵名排序。
- ⧉ **JSONPath 複製**：懸停節點即可複製精確的 JSONPath 路徑或節點值，方便對接腳本與程式碼。
- 🎨 **深色 / 淺色主題**：一鍵切換，護眼舒適。
- 💾 **匯入 / 匯出 / 拖曳**：支援檔案匯入、匯出下載、拖放檔案自動辨識格式。
- 🚫 **完全離線**：單檔即可執行，無建置、無依賴、無網路請求，斷網也能用。

## 🚀 快速開始

### 📦 環境需求

- 任一現代瀏覽器（Chrome / Edge / Firefox / Safari）
- （選用）Node.js ≥ 16 用於本機起服務
- **無需安裝任何依賴**，無需 `npm install`

### 🏃 方式一：直接開啟（最快）

```bash
git clone https://github.com/gitstq/JsonLens.git
cd JsonLens
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

### 🖥️ 方式二：本機起服務（推薦）

```bash
cd JsonLens
npm start              # 自動在 http://localhost:8080 啟動
# 或直接用 Node 執行
node server.js --port 8080
```

瀏覽器開啟 **http://localhost:8080** 即可。

### 🐍 方式三：Python 簡易服務

```bash
cd JsonLens
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 📖 詳細使用指南

### 1️⃣ 資料結構樹

開啟應用後，左側「源資料」面板已預填一份範例 JSON。右側「結構樹」會即時渲染為彩色樹形：點擊 `▾/▸` 可展開摺疊，懸停任一節點會浮現操作按鈕（上移 / 下移 / 刪除 / 新增 / 複製路徑 / 複製值）。

![結構樹渲染](docs/screenshot-tree.png)

### 2️⃣ 編輯資料

- **修改標量**：雙擊某個值（如 `"1.0.0"`），進入內聯輸入框，Enter 確認、`Esc` 取消。
- **新增子項**：懸停物件/陣列節點，點擊 `＋` 按鈕。
- **刪除 / 移動**：懸停節點點擊 `✕` 刪除，`⤒ / ⤓` 上移下移。

![線上編輯](docs/screenshot-edit.png)

### 3️⃣ 格式切換與互轉

頂部 **JSON / YAML / TOML / CSV** 標籤可隨時切換。切換時 JsonLens 會先解析目前資料，再無損序列化為目標格式，**資料不會遺失**。非常適合用 YAML 寫配置、用 JSON 傳介面、用 CSV 做表格的場景。

| 場景 | 推薦格式 |
|------|----------|
| 介面除錯 / 程式配置 | JSON |
| 維運 / CI 設定檔 | YAML |
| Rust / 現代工具配置 | TOML |
| 表格資料 / 批次匯入 | CSV |

### 4️⃣ 脫敏與隱私

點擊工具列 **◐ 脫敏** 按鈕，`password`、`apiKey`、`token`、`secret` 等關鍵欄位會自動打碼，方便在分享截圖或簡報時保護敏感資訊。再次點擊可恢復。

![脫敏示範](docs/screenshot-redact.png)

### 5️⃣ 統計與搜尋

- **▤ 統計**：彈出節點總數、最大深度、資料大小、型別分佈。
- **🔍 搜尋**：在結構樹頂部的搜尋框輸入關鍵字，即時高亮匹配節點。

## 💡 設計思路與迭代規劃

### 設計理念

JsonLens 堅持 **「零依賴、離線優先、隱私第一」** 的核心理念。所有解析器（YAML / TOML / CSV）均為 **自研實作**，不依賴任何第三方函式庫，因此可以做到單檔直開、完全離線、資料不出瀏覽器。介面遵循「資料透鏡」實驗室美學——深色底、霓虹高亮、克制排版，讓資料本身成為主角。

### 技術選型

- **原生 HTML / CSS / JavaScript（ES Modules）**：零建置、零依賴，任何能開網頁的裝置都能執行。
- **自研解析器**：覆蓋常見 YAML 子集（巢狀對映、序列、內聯陣列/對映、區塊標量、註解）、TOML（表、陣列表、內聯表、基礎型別）、CSV（含表頭/無表頭）。
- **Node 內建測試執行器**：無需額外依賴即可執行單元測試，確保解析器正確性。

### 迭代規劃

- [ ] 支援 JSON Schema 驗證與錯誤提示
- [ ] 增加主題色可自訂
- [ ] 支援更多格式（XML / INI / Properties）

## 📦 打包與部署指南

### 建置產物

```bash
cd JsonLens
npm run build        # 產生自包含的 dist/ 目錄
python3 -m http.server 8000 --directory dist
```

### 部署方式

- **靜態託管**：將 `dist/` 目錄上傳到 GitHub Pages、Netlify、Vercel、Nginx 等任一靜態託管，即可獲得線上存取位址。
- **內網 / 離線部署**：將 `dist/` 拷貝到任一內網伺服器或本機即可離線使用，無需網路。
- **桌面使用**：直接雙擊 `index.html`，無需任何伺服器。

### 相容環境

| 瀏覽器 | 版本 |
|--------|------|
| Chrome / Edge | 80+ |
| Firefox | 78+ |
| Safari | 14+ |
| Node.js（選用） | ≥ 16 |
